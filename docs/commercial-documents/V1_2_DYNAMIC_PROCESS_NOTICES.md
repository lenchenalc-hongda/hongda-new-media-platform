# 商务单据 V1.2 — 随报价大项自动生成产品 / 工艺说明

## 产品目标
- 根据报价中存在的产品大项，自动汇总相关条款；只有机器时仅生成机器条款，版费 + 花膜 + 机器时生成这三类条款，重复大项不重复输出。
- 当前支持 5 类：开版及铜版、凹版热转印花膜、数码热转印花膜、机器、热转印加工。
- 系统先从大项名称自动判断，业务员也可以在大项内选择正确说明类型、选择「不附加说明」。
- 每类说明可在当前单据单独改写及恢复默认，按语言分别保存；导出 / 导入原有 JSON 草稿能够保留配置。
- 仅填写了明细的大项参与触发；删掉最后一个对应大项，相关说明也自动消失。
- PDF 采用紧凑文本、无额外厚色块、各条尽量不跨页；已验收过的宏达图片 Header、金额计算、税务及红色总额栏均不改动。
- 报价单与机器合同都根据实际大项生成产品说明；机器合同仍独立保留已经要求的人工验收与保修条款。

## 默认中文说明

**开版 / 铜版**
> 铜版自开版日起保质期18个月；保质期内一切修补费用由我司承担。超过18个月且连续一年未下单的印版，我司直接作报废处理。

**凹版热转印花膜**
> （1）印刷色彩、套印精度存在一定批次差异，一般约为±半个PANTONE色卡号、±0.3mm；以双方确认的打样稿或客户提供的样板为准。需对实物样板的，应提供样板用于开版和打样。
> （2）烫印结合力应依据需方实际材质，由供方送样、需方试烫确认。

**数码热转印花膜**
> 数码热转印花膜仅按客户最终确认的电子图稿文件及其颜色生产；如有特殊颜色或对样要求，应在生产前提供参考并由双方确认。

**加工**
> 请确保客户来料清洁。我司入库后进行印前抽检；脏污超过双方确认的比例时，来料退回或另行协商处理。加工默认预留3%备品，并力求降低；产品难度较大时，备品比例需另行协商。

**机器**
> 设备默认供电220V/60Hz（销售可依机型修改），具体以双方最终确认的机型和配置为准。非人为因素造成的零部件故障，保修期由销售填写并经双方确认；保修范围及起算时间以双方书面确认为准。

## 需要业务确认的点
1. 中国大陆供电常见为 50Hz，不应把 220V / 60Hz 当作全部机型的技术承诺；按用户提供的默认值预填，并允许每次报价修改。
2. 用户尚未确定机器零部件保修期限：**机器报价保修期留空并阻止正式打印，必须填写确认的时长**；机器合同按其原有必填「保修及售后安排」执行。
3. “±半个 PANTONE 色卡号”保留当前业务提供的表述，正式成为客户验收指标前应补充双方约定的检测方法；常用 PANTONE 编号本身并非连续的色差数值。
4. “脏污超比例”保留双方约定的检验口径，不自行设定合格率阈值；“3%备品”按用户提供的原话，不擅自定义由谁承担或补充数量。
5. 中英文默认条款为草稿级的商务文字，特别是法定保修、容差、印版报废条件，对外使用前应由销售、技术与公司确认。

## 数据与安全边界
- 不改 Supabase SQL、RLS、权限、用户身份、客户/财务数据。
- 与之前相同，报价只存在浏览器内存或用户手动导出的本地 JSON，不新增云端保存。
- 不变更原报价单金额、客户搜索与税务说明、机器合同签字区域。
- 同一类型多大项只附加一次默认说明；修改单据文字不修改系统默认模板。
- 生产发布需现有 CI + Chromium PDF QA 及 PR 审核。

## 测试场景
- 只有机器 => 只有机器说明；机器保修期未填禁止打印，填后打印。
- 版费 + 凹版花膜 + 机器 => 三段说明；同类版费重复不重复说明。
- 数码花膜 + 凹版花膜 => 分开两段，不能混为一类。
- 加工 => 自动显示来料抽检和 3% 备品；只含无关运费时不自动添工艺说明。
- 手动设置类型、删除大项、切换中文/英文、自定义说明和旧 JSON 导入。
- Chromium 输出单类、三类、五类以及长篇多页 PDF，检查页内显示、不裁切、金额不改变。
