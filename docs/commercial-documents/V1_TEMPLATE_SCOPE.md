# HongdaOS 商务单据模板 V1（开发范围与验收）

## 已实现（独立开发分支）
- 所有已登录角色：admin、manager、operator、sales、viewer 均可进入 \`/commercial-documents\`。
- 左侧导航独立「商务单据」入口，首页复用导航分组。
- 两种模板：产品报价单、机器销售合同草稿；中文 / 英文界面标签，国内 / 外贸。
- 报价单 -> 自由增删排序的大项 -> 每个大项自由增删排序的产品明细。
- 行级数量 * 业务员输入单价，采用整数最小货币单位及 1/1000 数量计算。
- 每项小计、整体总额；仅单价目录不计入合计，混合报价时明确提示未计入目录行。
- 国内税务只有两个可选说明：「报价未含税，发票及税务安排另行确认」或「含13%增值税专用发票」。不计算或拆分税额。
- 红灰风格、正式宏达 Logo、A4 样式、浏览器打印/另存为 PDF。
- 机器合同要求人工填写付款、交付、验收、保修售后条款，包含双方签章区域。
- 页面可导出和导入 JSON 草稿文件（仅用户本地文件，非服务端资料库）。

## 尚未实现（需独立设计与财务确认）
- **无** Supabase 正式单据表、服务端持久化、历史版本和审计日志。
- **无** 客户 / 项目自动关联、自动生成单据编号。
- **无** 正式收款账户库及后台管理；不填入任何虚构/个人收款资料，正式合同付款信息需要后续联动。
- **无** 服务端 PDF 直下载；使用 Chrome/Safari/Edge 系统打印窗口选择「保存为 PDF」。
- **无** 经法务批准的机器合同条款库；模板内容属于草稿，不能视为已审核合同。
- **无** Packing List 正式模板。
- 未授权变更 Production SQL、数据、RLS、账号、薪资或财务来源。

## 测试点
1. admin/manager/operator/sales/viewer 均看到导航并能在登录状态访问。
2. 未登录不能打开模板。
3. 版费 + 花膜 + 机器的小计/总额正确，小数数量正确，不累加单价目录。
4. 两种税务说明切换时价格不会自动加13%或减税。
5. 每个大项及其明细可增删改排序，不影响别的组。
6. 机器合同未录入确认条款或包含无数量目录时不能导出。
7. 移动端切换预览及打印，超过一页时表头重复、页眉及合计不被截断。
8. 中文、英文、人民币、美金/欧元、长规格备注均能输出清晰 PDF。
9. 离开页面的草稿不在服务端留存，需要手动下载草稿 JSON。

## 部署门槛
- 此 PR 不执行任何数据库修改。
- CI 全绿和人工 PDF 样张验收后，单独确认是否合并到生产分支。
- 若开始正式单据留存和账户库开发，必须独立进行 RLS/权限/财务安全审查，不能用 localStorage 或 generic site_data 保存。
