# HongdaOS 商务单据 V1.1 — 表单与 PDF 规则

## 需求与实现
- 01 单据类型/销售区域/语言/币种保持原样；编号默认随机但可编辑，日期默认当天可改。
- 编号格式示例：HD-Q-2610-K7M4X8R2P5LF、HD-C-2610-K7M4X8R2P5LF。
- 新建/重置自动生成；变更单据类型、跨月变更日期时仅对自动编号重新生成。用户自定义编号保留。
- 02 卖方固定为广东宏达印业股份有限公司；不允许输入卖方主体、卖方地址及电话，PDF 也不展示地址/电话。
- 业务员默认并固定取当前登录账号可信身份中的姓名；历史 JSON 草稿导入时重新取当前登录人。
- 买方可搜索现有客户项目参考库、选择现有客户或手动输入新客户；保留联系人，移除客户地址。
- 付款预设：版费先付花膜月结、版费先付花膜发货前付款、月结、账期 N 天、机器定金50%发货前尾款结清、其他。
- 运输预设：EXW、DDP、含运费、不含运费、客户自提、其他。
- 预设自动填入最终条款编辑框，业务员可修改，PDF 与最终文字一致。
- 版费/花膜/机器大项、产品明细、小计/总计、税务说明不改动，不做13%自动加价或拆分。

## 数据与权限
- 编号使用浏览器加密随机源生成12位随机字符，隐藏连续业务量。
- **本版本没有正式单据数据库与唯一编号注册表**。随机编号自然重复概率极低，但员工手动改成相同编号时无法跨用户强制判重。严格唯一必须后续使用数据库 UNIQUE 约束。
- 客户搜索通过只读 API 访问 cpc_customer_references，继续执行现有组织隔离及 Supabase RLS；不扩大客户读取权限。没有读取权限的员工可手动输入。
- 不写客户主档、不更改客户所有权；历史 JSON 草稿导入时锁定卖方主体并清除隐藏地址/未经批准的收款账户信息。
- 不执行 Production SQL、RLS 或生产环境变量修改。

## 验收
1. 所有登录账号能使用报价模板；公司主体固定，业务员取登录人。
2. 有权限的员工能搜索选择客户，无权限者能手填。
3. 编号自然生成且可手动改，切换类型和跨月变更与编号前缀一致。
4. 六种付款方案和六种运输方案可选、可修改，PDF 正确显示。
5. 兼容导入旧版 JSON，并清理不可相信的卖方/账户信息。
6. 大项金额计算与税务选项保持原先结果。
7. CI、Vercel Preview 通过且 PR 审核后方可合并上线。
