# UI、权限与通知 V1

## 1. Hongda OS 入口

Workshop Order System 在 Hongda OS 中显示为一个业务门户：

- 生产下单
- 打烊申请
- 车间任务中心
- 排期看板
- 物料齐套
- 异常与阻塞
- 管理分析

生产下单与打烊申请必须是两个独立一级入口。

## 2. 办公室首页

### 我的待办

- 草稿未提交
- 车间退回补资料
- 缺图片/缺版本
- 等待项目负责人确认
- 打烊结果待确认

### 我的任务

按任务类型、客户、项目、状态、负责人、是否加急、货期筛选。

### 任务详情

首屏必须显示：

- 客户、项目、订单/申请编号
- 产品、数量、版本
- 当前状态
- 当前阻塞原因
- 花膜/夹具/来料/签样状态
- 当前生产基准图片
- 下一责任人和下一动作

## 3. 车间首页

建议使用大屏友好的列队卡片：

- 待确认
- 待物料
- 可排期
- 今日生产
- 生产中
- 打烊中
- 异常/暂停
- 待完工确认

每张任务卡至少显示：

- 类型
- 客户/产品
- 版本
- 数量
- 加急标识
- 计划日期
- 当前基准缩略图
- 三项资源状态
- 阻塞原因

## 4. 排期看板

视图：

- 日/周
- 按机台
- 按任务类型
- 按负责人

卡片显示：

- 项目/订单
- 产品
- 计划数量
- 预计工时
- 资源齐套状态
- 版本核对状态
- 优先级

拖动排期必须经过权限校验并记录审计；不能把未通过 readiness Gate 的任务拖入正式开工区。

## 5. 角色权限

### Office / Project Owner

- 创建和编辑草稿
- 提交
- 上传图片
- 设置当前生产基准
- 补资料
- 查看车间状态
- 确认打烊结果

不得：

- 直接修改车间技术参数
- 绕过开工 Gate
- 伪造技术/主管确认

### Technician

- 接收打烊/技术任务
- 填写参数
- 上传结果图片
- 提交结果判定
- 记录风险

不得：

- 修改客户订单数量/货期
- 单独放行生产开工

### Workshop Supervisor

- 接单
- 确认资源
- 排期
- 放行开工
- 暂停/恢复
- 完工确认

不得：

- 静默改写客户版本或确认样

### Quality

- 核对签样与验收标准
- 确认品质 Gate
- 暂停异常生产
- 记录放行/拒绝原因

### Manager/Admin

- 组织范围查看
- 资源和排期协调
- 规则/字典配置
- 审计查看

Production 配置、RLS 和数据迁移仍需独立 Human Gate。

## 6. 通知策略

避免所有状态都发通知，只通知需要行动的事件。

### 办公室收到

- 车间退回补资料
- 缺物料/图片/版本
- 排期确认
- 货期风险
- 打烊结果完成
- 生产异常/暂停
- 生产完成

### 车间收到

- 新提交任务
- 办公室补齐资料
- 版本/基准图片变更
- 加急状态变更
- 客户验收标准变更

### 管理者收到

- 逾期未接单
- 长时间待物料
- 高风险版本变更
- 已开工后版本变更
- 连续异常/暂停
- 排期冲突

## 7. 阻塞原因字典

至少包括：

- OFFICE_INFO_INCOMPLETE
- PRODUCT_IMAGE_MISSING
- FILM_IMAGE_MISSING
- CUSTOMER_SAMPLE_MISSING
- VERSION_MISMATCH
- FILM_NOT_READY
- FIXTURE_NOT_READY
- INCOMING_MATERIAL_NOT_READY
- SIGNED_SAMPLE_NOT_READY
- TECHNICAL_RISK_UNRESOLVED
- QUALITY_GATE_FAILED
- SCHEDULE_CAPACITY_UNAVAILABLE
- MACHINE_UNAVAILABLE
- OTHER

阻塞原因必须可统计，不能全部写成自由文本。

## 8. 无障碍与车间适配

- 桌面优先，适配 1366×768
- 车间按钮和状态点击区域更大
- 状态不能只靠颜色区分
- 重要图片支持全屏
- 支持键盘操作和清晰 focus
- 弱网络时显示同步状态和重试
- 关键提交防重复点击
