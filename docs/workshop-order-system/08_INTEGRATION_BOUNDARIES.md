# 与 Hongda OS 其他模块的集成边界 V1

## 1. Customer Project Center（CPC）

WOS 不重新创建客户归属和销售项目 SoT。

### CPC 保持权威

- 客户主档
- 项目主档
- 当前负责人/协作人
- 项目阶段
- 客户跟进事实
- 项目报告

### WOS 保持权威

- 生产单
- 打烊申请
- 车间接单
- 物料齐套
- 生产参考基准
- 技术参数
- 排期
- 开工/暂停/完工
- 车间阻塞与异常

### 关联方式

WOS 保存：

- `customer_id`
- `project_id`
- 必要展示快照（客户名、项目名、负责人名）

快照用于历史显示，不覆盖 CPC 当前事实。

生产/打烊状态可回写 CPC 的“关联制造状态摘要”，但不得让 WOS 自行改变客户归属或财务事实。

## 2. 项目复盘中心

生产异常达到规则时，WOS 可生成项目复盘草稿：

- 任务/订单引用
- 异常时间
- 阻塞/缺陷类型
- 相关图片
- 技术参数
- 当班人员
- 已采取动作

复盘草稿需要人工确认后才成为正式复盘。

## 3. 知识库

WOS 可引用：

- 材质工艺知识卡
- 胶水/离型/前处理规则
- 常见缺陷处理
- 夹具注意事项
- 包装规范

知识库内容用于建议和提示，不直接覆盖任务中的已确认生产基准。

## 4. 用户和角色

WOS 复用 Hongda OS 当前可信用户与 `profiles.id`。

不得创建独立影子用户表或依赖浏览器 localStorage 作为正式身份。

## 5. 通知

V1 先使用站内通知/待办。

未来企业微信通知只发送状态摘要和链接，不在外部消息中暴露完整客户图片、Production secret 或敏感技术资料。

## 6. Storage

正式图片使用私有 storage：

- WOS 负责图片 metadata、版本和 baseline
- Storage 负责文件对象
- 服务端负责授权访问
- 外部公开链接不是正式设计

## 7. AI 辅助边界

AI 可以：

- 检查缺字段
- 总结风险
- 提议阻塞原因
- 从文字提取结构化要求
- 帮助比较两个版本说明
- 建议排期优先级

AI 不可以：

- 替技术员判定“通过”
- 替主管放行开工
- 自动改客户确认样
- 自动承诺货期
- 自动修改客户归属
- 将图片识别结果直接视为生产事实

所有 AI 结论默认是建议，关键生产事实需要人工确认。

## 8. 编号规则建议

- Production Order：`PO-YYYYMM-####`
- Sampling Request：`SR-YYYYMM-####`
- Sampling Attempt：`SR-...-A01`
- Production Run：`PO-...-R01`

正式编号生成必须在数据库/server 侧保证唯一，不在浏览器本地递增。
