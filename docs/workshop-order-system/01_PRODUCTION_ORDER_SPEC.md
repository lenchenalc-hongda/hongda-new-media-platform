# 生产下单数字化规格 V1

## 1. 使用场景

办公室在订单进入大货阶段后创建生产单。系统先校验资料完整性，再由车间确认物料、版本和可生产条件，最后进入排期和开工。

## 2. 办公室填写区

### 基本信息

- 客户名称
- 关联客户 ID
- 关联项目 ID
- 销售负责人
- 项目/业务负责人
- 填写日期
- 订单编号
- 产品名称
- 是否加急
- 版本号
- 优先级

### 签样与生产细节

- 签样人
- 签样日期
- 产品说明
- 产品材质
- 表面处理
- 满版/局部图案
- 图案接口偏差/接缝限距
- 对照样说明
- 位置基准（距杯口/底部等）
- 其他注意事项
- 可接受缺陷范围
- 客户验收标准

### 数量与交付

- 总生产数量
- 当前批次数量
- 出货数量
- 出货日期
- 是否分批交付
- 后续批次日期/数量
- 货期说明

### 包装与标识

- 包装方式
- 装箱量
- 唛头/编号/标签规则
- 其他包装要求

### 生产参考图片

支持多图上传并分类：

- 花膜图案
- 产品实物
- 客户确认样
- 大货签样
- 包装/标签参考
- 其他生产参考

至少一个图片集合必须被标记为“当前生产基准”。

## 3. 车间确认区

### 资源到位

| 资源 | 状态 | 预计到位 | 实际到位 | 负责人 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 花膜 | 未到/部分到/已到/已核对 | | | | |
| 夹具 | 未到/制作中/已到/已确认可用 | | | | |
| 来料/胶件 | 未到/部分到/已到 | | | | |
| 签样 | 未到/已到/已确认 | | | | |

### 技术与风险

- 可能难点与风险点
- 来料保护要求
- 胶轮/夹具是否可能损伤来料
- 推荐机台
- 预计效率
- 预计工时
- 前处理要求
- 过程巡检频率
- 停机条件

### 三方确认

- 业务/销售确认
- 技术员确认
- 车间主管确认
- 品质确认（订单需要时）

## 4. 生产下单 Gate

### 可提交

必须满足：

- 客户、产品、订单编号、数量、版本号存在
- 至少上传产品实物图
- 已有花膜时上传花膜图案图
- 客户提供确认样时必须上传

### 可排期

必须满足：

- 办公室资料完整
- 花膜/夹具/来料状态可满足排期
- 当前生产基准图片已设置
- 图片版本与订单版本一致
- 车间已接单

### 可开工

必须满足：

- 花膜已到并核对
- 夹具已到并确认可用
- 当前批次来料已到
- 签样/确认样已到（需要时）
- 技术确认完成
- 车间主管确认完成
- 当前生产基准图片已由车间核对
- 无未解决的阻塞项

## 5. 异常与退回

车间可以选择：

- 要求补资料
- 退回修改版本
- 标记物料未齐
- 标记技术风险待确认
- 暂停生产
- 拒绝开工

每次退回必须填写结构化原因和说明，并记录操作人、时间和之前状态。
