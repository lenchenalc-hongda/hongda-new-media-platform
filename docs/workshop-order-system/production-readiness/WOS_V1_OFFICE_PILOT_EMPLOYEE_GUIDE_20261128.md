# WOS V1 办公室试点操作说明

适用人员：Jake Wu  
账号角色：Sales（保持不变）

## 登录

1. 打开 `https://www.hongdaprinting.tech/login`。
2. 使用 `jake.wu@hongda.cn` 的正常密码登录。
3. 进入“车间订单” → “生产下单”。

## 创建订单

1. 选择客户对应的 CPC 客户。
2. 选择该客户下状态为 active 的项目。
3. 填写订单编号、产品、数量、交期、材质、验收标准、包装和唛头规则。
4. 订单编号必须唯一。
5. 上传四类 PNG：
   - 产品图片
   - 花膜图案
   - 客户确认样
   - 大货签样
6. 点击“创建、验证四图并正式提交”。
7. 等待页面显示数据库确认成功。
8. 记录页面显示的订单 ID。若网络结果未知，保持原页面原样重试，不要重新创建第二张订单。

## 车间退回后的修订

1. 回到“生产下单”。
2. 找到状态为 `NEEDS_INFORMATION` 的订单。
3. 展开“当前版本、退回原因与图片缺口”。
4. 只修改需要修订的字段。
5. 填写修订原因，点击“保存六字段修订”。
6. 上传 V2 的四类新版 PNG。
7. 点击“验证并登记新版四图”。
8. 等待四图验证完成后，填写原因并点击“重新提交车间复核”。
9. 确认订单版本和状态已更新。

## 权限边界

Jake 可以：

- 创建自己负责的订单；
- 上传和提交当前版本四图；
- 查看自己被退回的订单；
- 修订并重新提交。

Jake 不可以：

- 代替车间接单、退回或复核；
- 登记物料或确认 CURRENT Baseline；
- 进行 Office/Workshop 双签；
- 代替 Manager 放行开工；
- 把 Sales 角色改成 Operator。

车间操作需要另外绑定的独立 Operator 账号。

## 异常处理

- 页面提示版本冲突：刷新订单，不要重复点击。
- 图片验证失败：确认文件是真实 PNG，文件名不能包含 `..`。
- 客户或项目不可选：联系管理员核对 CPC 客户、项目和负责人是否 active。
- 403/401：重新登录；不要借用他人账号。
- 提交结果未知：保留当前订单 ID 和页面提示，原样重试，不要新建订单。
