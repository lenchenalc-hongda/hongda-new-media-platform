# WOS V1 办公室操作指引

适用页面：`https://www.hongdaprinting.tech`

## 新建订单

1. 登录后进入“车间订单” → “生产下单”。
2. 选择有效的 CPC 客户和项目。
3. 填写订单编号、产品、数量、交期和验收要求。
4. 上传产品图片、花膜图案、客户确认样、大货签样四类 PNG。
5. 点击“创建、验证四图并正式提交”。
6. 以页面成功回执为准，不要仅凭按钮点击判断成功。

## 接收退回并修订

1. 在“生产下单”页面查看车间退回原因。
2. 修改资料后点击“保存修订”。
3. 必须重新上传当前版本四类 PNG，不能沿用旧版图片。
4. 填写修订原因并点击“重新提交车间复核”。

## 图片 Baseline 与 Office 签认

1. 车间复核到 `WAITING_MATERIAL` 后，打开当前订单。
2. 如 Proof 已过期，点击“重新核验当前四图 Proof”。
3. 单张失败时，按页面显示的图片类别点击“重试失败图片”。
4. 选择当前版本四图作为 Baseline。
5. 完成办公室签认后，通知车间继续。

## 常见异常

- 图片打不开：重新导出标准 PNG，不要改扩展名冒充 PNG。
- 上传中断：刷新订单，确认是否已有成功回执；不要连续重复提交相同文件。
- Proof 过期：重新核验当前四图，不要重新上传相同图片。
- 客户改图：必须产生新版本并重新验证四图，旧签认自动失效。
- 订单被错误退回：按退回原因修订并重新提交，不要等待管理员改数据库。
- 网络断开：恢复后刷新订单和回执；页面显示结果未知时不要连续点击。
