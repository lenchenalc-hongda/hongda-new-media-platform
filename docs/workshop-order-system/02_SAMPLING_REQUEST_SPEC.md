# 打烊申请数字化规格 V1

## 1. 使用场景

打烊申请用于验证产品是否适合热转印、是否达到大货标准，以及记录实际可复制的技术参数、风险和结果照片。

生产下单和打烊申请必须保持两个独立入口。打烊通过后可生成生产单草稿，但不得直接跳过生产下单的物料、签样和开工 Gate。

## 2. 项目负责人填写区

### 基本信息

- 客户名称
- 关联客户/项目
- 产品名称
- 产品负责人
- 申请日期
- 是否加急
- 版本号
- 预计完成日期

### 打烊阶段

- 未立项：重点验证可生产性、附着力、接口、拉伸、切边
- 已立项：重点验证位置、接口、客户目标效果和大货效率

### 打烊目标（多选）

- 可生产性
- 附着力
- 接口处理
- 拉伸情况
- 切边效果
- 位置基准/对位
- 最大可印刷位置
- 大货效率预估
- 其他目标

### 产品与来料信息

- 产品材质
- 表面处理（喷漆/涂层等）
- 样品来料数量
- 所需良品数量
- 是否有专用夹具
- 夹具编号/状态
- 大货数码膜/起版膜/常规膜类型
- 花膜版本
- 打烊风险点
- 其他注意事项

### 参考图片

- 产品实物照片（至少 1 张）
- 花膜图案/膜样照片（已有花膜时必需）
- 客户目标效果/确认样照片（客户提供时必需）
- 位置/接口标注图
- 其他技术参考图

## 3. 技术员填写区

### 技术参数

- 温度
- 烫印时间
- 胶轮硬度
- 活架/死架
- 压力（轻/中/重，可补充数值）
- 表面处理/前处理
- 机台
- 夹具
- 花膜版本
- 调机次数
- 预计大货效率

### 结果判定

只能选择一个：

- 通过：达到可大货标准
- 不通过：已完成打烊，但当前方案无法大货
- 无法打烊：夹具不匹配、产品不适合、来料问题或其他前置条件不满足

### 结果记录

- 不通过/无法打烊原因
- 大货风险点
- 推荐改善方案
- 是否建议重新打烊
- 是否可转生产
- 技术员签名/确认
- 打烊日期
- 项目负责人确认

### 结果图片

打烊完成后支持上传：

- 正面效果
- 接口/接缝
- 边缘/切边
- 拉伸位置
- 附着力测试后效果
- 不良/风险细节
- 整体结果

结果图片与本次技术参数、版本和判定绑定，不能被后续打烊静默覆盖。

## 4. Gate

### 可提交

- 基本信息完整
- 产品材质和表面处理已填写
- 产品实物图已上传
- 打烊目标至少选择一项
- 样品来料数量和所需良品数量已填写

### 可开始打烊

- 产品/来料已到
- 夹具已到或已确认无需专用夹具
- 花膜已到或任务明确为膜方案验证前置阶段
- 当前版本图片已核对
- 技术员已接单

### 可关闭

- 技术参数完整
- 结果判定已选择
- 风险/原因已填写（非“通过”时必需）
- 至少上传一张结果图
- 技术员确认
- 项目负责人确认

## 5. 转生产单规则

“通过”后允许生成生产单草稿，继承：

- 客户/项目/产品
- 产品材质和表面处理
- 当前花膜与版本
- 技术参数
- 大货风险点
- 夹具信息
- 当前基准图片
- 打烊结果图片

生产单仍需补充数量、货期、包装、签样和资源到位信息。
