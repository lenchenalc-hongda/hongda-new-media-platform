# 05 页面与 UX 规格

> SPEC_LOCK_VERSION = GLH-SPEC-V1.0
> FROZEN = YES

Desktop-first, salesperson daily-use design. Minimum practical desktop target: 1366x768.

## 01 Today / 今日工作台

Show action-oriented counts:

- new leads;
- waiting for human;
- due today;
- newly completed qualification;
- quotation follow-up;
- sample follow-up;
- overdue / dormant.

Show "my priority customers" below the counts.

## 02 Unified Inbox / 统一收件箱

Three-column layout:

- left: queues + conversations;
- center: full original conversation;
- right: customer card + AI summary + score + completeness + missing fields + next action.

Primary actions:

- Take Over
- Transfer/Assign
- Create task
- Generate draft
- Pause/resume AI only where permitted.

## 03 Lead Library / 客户线索库

Search/filter by:

- country;
- source;
- requirement;
- grade;
- lifecycle;
- owner;
- follow-up due;
- ad/creative where present.

## 04 Lead Detail / 客户详情

Tabs/sections:

- overview;
- structured requirement profile;
- conversation;
- tasks/follow-ups;
- assignment history;
- score history;
- AI actions;
- audit timeline;
- later: quote/sample references.

## 05 My Tasks / 我的待办

Today / overdue / upcoming and type filters.

## 06 Ads & Lead Quality / 广告与线索分析

V1 analytics stay simple:

- leads per source/creative;
- qualified leads;
- A/B grade distribution;
- quotation/sample/won counts when data exists;
- country/product/requirement breakdown.

Do not turn V1 into a large BI project.

## 07 Settings / 管理设置

Admin/manager-restricted:

- users/role references;
- assignment rules;
- scoring rules;
- AI mode/rules;
- channel connection status;
- approved prompt/template references;
- audit access.

The app must remain usable for human work when AI is unavailable.
