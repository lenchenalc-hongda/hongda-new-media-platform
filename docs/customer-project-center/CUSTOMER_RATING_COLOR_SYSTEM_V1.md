# CPC 客户双评级｜视觉配色规范 V2（2026-10-25）

本规范是 HongdaOS CPC 客户价值评级最新配色权威定义。统一适用于客户列表、客户详情、潜力评分试算、评级颜色说明，以及后续新建的管理看板。不调整评分标准、人员权限、财务规则及历史数据。

## 双维度识别规则

- **R 实际评级**：深/明亮的实心方形标签，保留「实际 R-SS / R-S / …」，依据核实回款；回款尚未确认时使用 **R-N 灰色未归类**。
- **P 潜力评级**：浅色填充 + 彩色粗描边的圆形胶囊标签，保留「潜力 P-SS / P-S / …」；客户负责人或有效关联项目负责人保存后立即生效，无需经理审核。
- **未保存的试算或历史旧草稿**：P 相应色系 + 虚线边框 +「试算·未生效」，不覆盖当前已正式生效的 P 等级。
- **N（未归类）**：无论 R/P 都保持完全一致的中性灰色并显示「未归类」；未知不等于最低等级 D。

## 实现原则和边界

1. 全部颜色仅由 `src/components/customer-projects/customer-rating-colors.ts` 统一维护。采用静态 Tailwind 完整类名，确保生产构建扫描到所有样式。
2. `src/components/customer-projects/CustomerRatingBadge.tsx` 提供同一标签组件和展开式说明，客户列表、详情、试算共用，不重复硬编码。
3. 颜色属于辅助视觉编码；无障碍场景始终以 R/P 前缀、等级文字、N「未归类」及试算状态作为辨识依据。
4. R/P 等级阈值、客户负责人及项目负责人可编辑权限、客户主数据、回款、薪资提成、销售计划和审计逻辑均不受影响。
5. 原有老客户 A/B/C 回访频次/关系分类与客户价值 R/P 等级不同，不能套用此颜色体系或修改其业务语义。

## 发布与验收

- SS亮金、S红、A蓝、B绿、C紫、D浅棕、N灰必须与真实页面颜色说明一致。
- R与P同级同色系、但外形实心方牌/浅底圆牌清晰不同。
- 高亮浅底的 SS 和 D 使用深色字体；N 的 R、P 均为中性灰。
- 前端改动只通过 CI 和 Preview 验收；正式合并与 Production 发布需单独授权。
