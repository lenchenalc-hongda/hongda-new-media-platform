# CPC 客户双维评级｜实际评级金额区间冻结 V1.0（2026-10-25）

**Owner-approved business thresholds.** This document freezes the **R/实际评级** amount bands only. It does not approve a Production migration, finance-data import, automatic overwrite, or changes to commission/payroll logic. CPC is NOT the source of financial truth.

## 1. 实际评级（过去12个月有效净回款，人民币）

等级须互斥；按**金额人民币元**定义边界：

| 实际评级 | 有效净回款区间 | 业务称谓 |
| --- | --- | --- |
| SS | > 3,000,000 CNY | 超级核心客户 |
| S | > 1,000,000 且 <= 3,000,000 CNY | 核心大客户 |
| A | >= 500,000 且 <= 1,000,000 CNY | 高价值客户 |
| B | >= 100,000 且 < 500,000 CNY | 重点经营客户 |
| C | >= 10,000 且 < 100,000 CNY | 一般客户 |
| D | < 10,000 CNY（财务数据核实完整，含 0 元） | 低贡献/未成交客户 |
| N | 未分级、历史回款不完整或财务证据未经核验 | 不可推断为 0 元 |

**交界值明确定义：** 恰好 300 万=S；恰好 100 万=A；恰好 50 万=A；恰好 10 万=B；恰好 1 万=C。若回款为0且核实期间完整则D，不是N。

技术计算采用**整数人民币分**（CNY cents/fen），不得用浮点数进行金额比较。判级纯函数：`src/lib/customer-projects/customer-actual-rating.ts`。

## 2. 数据权威、时间和可用性

- 财务权威数据仍属现有车间/财务系统（`receiptRecords`），CPC **只读**已经财务确认的客户净回款，不允许新建独立回款台账或修改历史财务。
- 推荐使用最近12个**完整自然月**的已确认净回款，每月结算后更新评级快照；正式统计周期/会计期间由财务确认后作为系统参数固定。数据必须记录周期起止、计算时间和财务来源版本。
- 净回款 = 经财务确认的有效收款 - 经财务确认的退款、冲销、作废反转等；去重、关联真实客户编号 `external_customer_id`。预收款/跨公司回款归属必须经财务确认，不得推断；如原始记录为外币，只有经财务批准的汇率换算结果才能纳入CNY等级。
- 如果完整性无法验证、缺少权威收款记录、客户编号无法关联、来源不可访问、账期不完整或只有报价/意向订单，则状态为 `ungraded`，评级 N（**严禁按0元判D**）。
- 财务核实后即使净回款为0元或因退款呈负值，也可判D；负值应另行触发财务异常检查，不允许静默忽略。
- 客户的真实金额及评级应保留财务数据来源、周期和计算版本；后续回款冲销需重新计算，但不能反向篡改既有月度评级快照。
- 实际评级只能由权威财务数据计算，业务员不可人工调整；有争议由财务改正权威记录、重算并保留审计。

## 3. 与潜力评级和现有回访分类的隔离

- **P/潜力评级**与R评级彼此独立：业务员填写未来12个月实际机会、工艺匹配、项目成熟度、客户关系和合作价值，管理者复核高评级。该维度的打分区间与本文件R等级阈值无关，不因R=SS就自动P=SS。
- 现有 `old-customer-proactive.ts` 使用A/B/C/UNKNOWN确定关系回访周期（30/60/90天），是**回访建议分类**，不能当做或覆盖此次R级别。未来UI务必显示“实际评级 R-SS”与“关系回访分类 A”以避免混淆。
- SS/S客户不自动获得额外财务权限；评级与提成、工资、财务锁定数据完全脱钩；高风险应收和一次性设备采购另以风险/采购模式标签呈现。

## 4. 实施范围与后续门槛

- 本次：Owner-approved R等级边界、独立纯函数、单元测试、规范文档。在未实现权威财务读取契约前**不对152个正式客户自动评分、不替换现有回访分级、不修改Production**。
- 后续由CPC项目推进：评估客户ID跨系统映射；确认财务读接口和完整性；数据模型/权限/审计设计；测试库验收；经独立审批后发布显示、筛选与团队看板。
- 所有用户端显示的等级应具有证据状态（verified/ungraded），无法取到权威数据时展示 **N 未分级**。

## 5. 验收用例

- 金额：9999.99→D、10000→C、99999.99→C、100000→B、499999.99→B、500000→A、1000000→A、1000000.01→S、3000000→S、3000000.01→SS。
- 财务数据未知/缺失→N；财务确认完整且0元→D。
- 潜力级别和旧A/B/C回访建议不被任何R分级代码写入或覆盖。
